# 铁砧工艺：流体拓展

本模组为《铁砧工艺》添加了一些流体，也许会有一些作用。

- **熔融宝石与熔融金属**：共 17 种熔融流体（6 种宝石 + 11 种金属）
- **功能性流体**：浮霜流体、余烬流体、诅咒金流体
- **熔融与冷却**：方块或材料在锅里熔成一桶流体；铁砧砸在满锅熔融流体上就冷凝回方块
- **矿石转化**：少量宝石熔液作催化剂，把金属熔液"重新长"成对应的矿石
- **合金**：熔融皇家钢、磁铁块

流体都能装桶，也能倒进<ref item="anvilcraft:large_cauldron"/>、<ref item="anvilcraft:fish_tank"/>与炼药锅。
