# 远古残骸

用**时移**把下界合金"还原"成远古残骸：

- <ref item="minecraft:netherite_ingot"/> + 装满<ref item="minecraft:lava"/>的炼药锅 → 时移 → <ref item="minecraft:ancient_debris"/>
- <ref item="minecraft:netherite_scrap"/> + 熔融钨锅 → 时移 → <ref item="minecraft:ancient_debris"/>

两条都消耗锅里的一桶（1000mB）流体。

# 浮霜金属块
