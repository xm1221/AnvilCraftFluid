# 矿石转化

在<ref item="anvilcraft:large_cauldron"/>里，少量**宝石熔液**当催化剂，大量**金属熔液**就会"重新长"成对应的矿石。

- **10mB 熔融红宝石** + 250mB 熔融金属 → 1 个**深层**矿石
- **10mB 熔融蓝宝石** + 250mB 熔融金属 → 1 个**浅层**矿石

金属与产物的对应：

| 熔融金属 | 深层矿石 | 浅层矿石 |
| --- | --- | --- |
| 熔融铁 | <ref item="minecraft:deepslate_iron_ore"/> | <ref item="minecraft:iron_ore"/> |
| 熔融金 | <ref item="minecraft:deepslate_gold_ore"/> | <ref item="minecraft:gold_ore"/> |
| 熔融铜 | <ref item="minecraft:deepslate_copper_ore"/> | <ref item="minecraft:copper_ore"/> |
| 熔融钨 | <ref item="anvilcraft:deepslate_tungsten_ore"/> | — |
| 熔融铅 | <ref item="anvilcraft:deepslate_lead_ore"/> | — |
| 熔融银 | <ref item="anvilcraft:deepslate_silver_ore"/> | — |
| 熔融锡 | <ref item="anvilcraft:deepslate_tin_ore"/> | — |
| 熔融锌 | <ref item="anvilcraft:deepslate_zinc_ore"/> | — |
| 熔融钛 | <ref item="anvilcraft:deepslate_titanium_ore"/> | — |
| 熔融铀 | <ref item="anvilcraft:deepslate_uranium_ore"/> | — |

<tip>
《铁砧工艺》的金属只生成**深层**矿石，所以除原版铁、金、铜之外都没有浅层版本。
</tip>

# 绿宝石

绿宝石自成一档，用熔融绿宝石来"长"：

- 10mB 熔融蓝宝石 + 250mB 熔融绿宝石 → <ref item="minecraft:emerald_ore"/>
- 10mB 熔融红宝石 + 250mB 熔融绿宝石 → <ref item="minecraft:deepslate_emerald_ore"/>
